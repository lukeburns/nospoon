v86 in the browser

After npm run vendor and npm run build, v86 assets ship beside this page under /v86/ (same origin). Browser-net uses the same query parameters as examples/simple (proxyHost, wsHost, …). Use ?controlOrigin=… only if you host the UI elsewhere but pull /v86/* from another origin.

Prefetch disk chunks from the nospoon repo root: npm run fetch-freebsd-disk (~2 GiB under lib/v86/guest/freebsd/). Cold boot is slow; IndexedDB snapshot speeds restarts. Click the emulated screen for keyboard focus. In the guest, dhclient then bridge SSH (or raw TCP).

Prefilled from whois when the page host is a CID-shaped label.
